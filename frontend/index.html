Can't connect to your local AI?
  1. Make sure Ollama is running and a model is installed.
  2. Launch the companion app and keep it open.
  3. Open the website from the companion's browser window.
  4. If it still fails, inspect the browser console and companion terminal.

The website cannot install software or start Ollama on its own.

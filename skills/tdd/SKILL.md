# Skill: tdd

Test-driven development skill.

1. Clarify the behaviour to implement.
2. Write a failing test first (write_file a test_*.py).
3. Run the test and confirm it fails for the right reason (run_python / pytest).
4. Write the minimal implementation to make the test pass.
5. Re-run tests.
6. Refactor under green tests.
7. Add a couple of edge-case tests.

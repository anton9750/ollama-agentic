# Skill: implement

Production implementation skill.

1. Clarify acceptance criteria and edge cases.
2. Inspect the workspace with list_dir / search_files / read_file if relevant.
3. Design a minimal, clean module structure.
4. Write complete, runnable files with write_file (all imports, types, error handling).
5. Run syntax_check on every new .py file.
6. Optionally add a tiny smoke test via run_python.
7. Summarize what was created and any remaining risks.

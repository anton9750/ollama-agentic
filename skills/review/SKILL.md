# Skill: review

Code review skill.

1. Locate the relevant files (list_dir, search_files, read_file).
2. Score overall quality 1-10.
3. Check:
   - Correctness & edge cases
   - Security (injection, secrets, auth)
   - Error handling & logging
   - Readability & naming
   - Tests present?
   - Over-engineering
4. List concrete issues ranked by severity.
5. Propose mandatory fixes (be specific about file + line / function).
